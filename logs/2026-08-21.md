# Virae.ai 项目变动总结 · 2026-08-21 · 22:00 CST

1. Strategy Plaza 上线，分享与复制 Agent 更安全：用户可以浏览其他人主动公开的手动参数快照或 Auto Agent，按最新发布、复制热度和策略筛选，并查看由系统计算的扣费后收益、胜率、样本量与风险提示；复制后只会创建一个归自己控制、默认暂停的独立 Agent。手动 Agent 会复制发布时的固定配置，Auto Agent 则复制同一套系统管理模式而不会暴露或冻结动态参数；作者身份会匿名化，账户、持仓、待成交订单和邮箱不会公开。影响：桌面端、移动端、后端。（polybot：[b7b4b9b7](https://github.com/Virae-Labs/polybot/commit/b7b4b9b7)、[4c29b895](https://github.com/Virae-Labs/polybot/commit/4c29b895)、[4f512b19](https://github.com/Virae-Labs/polybot/commit/4f512b19)；poly-terminal：[6b945b37](https://github.com/Virae-Labs/poly-terminal/commit/6b945b37)、[3818edd9](https://github.com/Virae-Labs/poly-terminal/commit/3818edd9)）

2. AI Agent Builder 支持用对话创建 Agent：用户可以直接描述币种、15 分钟或 1 小时周期、预算和下单方式，系统会把对话整理成可审阅的草稿，并在通过当前可用性与风险校验后等待明确确认，再创建真实 Agent；支持单币种 Crypto Tail 与跨币种 Agent Group，每次 AI 回复消耗 1 Credit。对话历史、草稿状态、Credits 用量和创建结果都会保留，页面也补充了键盘可达性和更清晰的会话记录。影响：桌面端、移动端、后端。（polybot：[42e9d8ee](https://github.com/Virae-Labs/polybot/commit/42e9d8ee)；poly-terminal：[ae5c38db](https://github.com/Virae-Labs/poly-terminal/commit/ae5c38db)、[8be5de4b](https://github.com/Virae-Labs/poly-terminal/commit/8be5de4b)）

3. AI Builder 内可直接购买 Credits：余额不足时无需离开创建流程，用户可在对话页选择 pUSD 套餐、完成二次验证并跟踪订单状态；同一弹窗可切换查看历史订单和链上交易，购买完成后会刷新可用 Credits。影响：桌面端、移动端。（poly-terminal：[782cde44](https://github.com/Virae-Labs/poly-terminal/commit/782cde44)）

4. Agent 与 Paper 策略在手机和大量任务场景下更容易浏览：策略库新增 15m/1h 周期及 BTC、ETH、SOL、DOGE、XRP、BNB 资产筛选，分类可以折叠，Paper 策略和任务可切换网格或紧凑列表；移动端顶部可稳定弹出交易场所选择器并直接显示现金余额，账户摘要、安全规则和创建步骤也压缩了无效留白。影响：桌面端、移动端。（poly-terminal：[f1d4140b](https://github.com/Virae-Labs/poly-terminal/commit/f1d4140b)、[c6b3fe40](https://github.com/Virae-Labs/poly-terminal/commit/c6b3fe40)、[7e4cd6c4](https://github.com/Virae-Labs/poly-terminal/commit/7e4cd6c4)、[395c8b6f](https://github.com/Virae-Labs/poly-terminal/commit/395c8b6f)、[94fdfe59](https://github.com/Virae-Labs/poly-terminal/commit/94fdfe59)）

5. Agents 收益与模拟概览刷新更快、筛选结果更一致：账户收益历史按用户只加载一次，再依据当前运行状态和策略在本地投影，减少重复请求并避免不同用户或筛选条件之间复用错误数据；任务骨架与收益摘要会并行加载，刷新过程有明确状态。后端同时减少模拟总览读取字段、批量保存摘要，并复用已加载任务计算收益，降低大量 Agent 和策略同时展示时的等待与数据库压力。影响：桌面端、移动端、后端。（polybot：[a5bf03f8](https://github.com/Virae-Labs/polybot/commit/a5bf03f8)、[62a0e01e](https://github.com/Virae-Labs/polybot/commit/62a0e01e)；poly-terminal：[adf2bab6](https://github.com/Virae-Labs/poly-terminal/commit/adf2bab6)、[c9e04c80](https://github.com/Virae-Labs/poly-terminal/commit/c9e04c80)）
